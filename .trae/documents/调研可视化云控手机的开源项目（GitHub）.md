## 需求聚焦
- 必需功能：通过 Web/云端执行安装 APK、重启（reboot）、模拟电源键（锁屏/点亮），可视化或至少设备列表与远程命令
- 可自建部署，支持多设备管理更优

## 候选方向
- DeviceFarmer/STF（OpenSTF 继任）：Web UI 管理设备，支持 APK 安装、重启、按键事件（含电源键）、文件传输、ADB shell
- OpenATX/atxserver2：设备农场管理，支持远程安装 APK、重启与基础控制；适合大规模设备池
- WebADB（yume-chan/adb）：浏览器直连单设备，支持安装 APK 等；多设备与云端管理较弱，但轻量
