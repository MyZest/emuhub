## 问题分析
- 在 Apple Silicon 上本地构建使用 `linux/amd64`（QEMU 仿真）会显著变慢；同时 Ubuntu 默认源（`archive.ubuntu.com`）经由 Docker Desktop 的代理（见 IP `198.18.68.70`）可能导致 `502 Bad Gateway`。
- 当前 Dockerfile 使用 `dpkg --add-architecture i386` 与 Nodesource 安装 Node.js，都会增加下载体量与失败概率。
- 还有 ENV 行一次性声明并在同一行引用 `$ANDROID_HOME`，会触发 undefined 警告。

## 方案目标
- 加速 apt、npm 阶段；减少失败重试；可按地域切换镜像。
- 修复 ENV 变量声明问题，避免构建警告。
- 兼容 Apple Silicon 本地构建，尽量避免慢速的 amd64 仿真。

## 具体改动（Dockerfile）
1. 顶部启用 BuildKit 语法以使用缓存挂载：
   - `# syntax=docker/dockerfile:1`
2. 拆分 ENV：先定义 `ANDROID_HOME/SDK_*`，再单独设置 `PATH`，避免 undefined 变量警告。
3. 增加可选镜像源参数并重写 `sources.list`：
   - `ARG UBUNTU_MIRROR=archive.ubuntu.com`
   - 将 `deb http://...` 重写为 `deb https://$UBUNTU_MIRROR/...`（可选：`mirrors.aliyun.com`、`mirrors.tuna.tsinghua.edu.cn`、`mirrors.ustc.edu.cn`、`azure.archive.ubuntu.com`）。
4. 加入 apt 可靠性与缓存：
   - 写入 `/etc/apt/apt.conf.d/99retries`：`Acquire::Retries "5"; Acquire::http::Timeout "30"; Acquire::https::Timeout "30";`（可选禁用代理：`Acquire::http::Proxy "false";`）。
   - 使用 BuildKit 缓存挂载：
     - `RUN --mount=type=cache,target=/var/cache/apt --mount=type=cache,target=/var/lib/apt apt-get update -yqq && apt-get install -y --no-install-recommends ... || apt-get -y --fix-missing install ...`
5. 精简 32 位架构：
   - 增加 `ARG ENABLE_I386=true`，仅在需要时执行 `dpkg --add-architecture i386` 与安装 `:i386` 依赖；默认关闭可显著减少下载体量，特别是 ARM 主机。
6. Nodesource 备选与重试：
   - `curl -fsSL https://deb.nodesource.com/setup_18.x | bash -` 增加 `--retry 5 --retry-delay 3`；若失败，回退到 `apt-get install -y nodejs` 或改用官方 tarball 安装。
7. npm 缓存与镜像：
   - 使用 BuildKit 缓存挂载 `--mount=type=cache,target=/root/.npm`；
   - 可选设置 `npm config set registry https://registry.npmmirror.com`（国内网络时）。

## 构建建议（Mac 本地）
- 若不依赖 `i386`：优先构建 ARM64 变体，避免 QEMU：
  - `docker buildx build --platform=linux/arm64 --progress=plain --build-arg UBUNTU_MIRROR=mirrors.aliyun.com -t emuhub:local .`
- 若必须 `i386/amd64`：仍可指定更快镜像与重试：
  - `docker buildx build --platform=linux/amd64 --progress=plain --build-arg UBUNTU_MIRROR=azure.archive.ubuntu.com -t emuhub:local .`
- 如网络环境不稳定：
  - 使用 CI 远程构建（GitHub Actions 已可配置多架构），本地仅拉取镜像；或在本地启用 `apt-cacher-ng` 代理加速。

## 验证
